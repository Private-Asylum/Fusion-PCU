# Fusion PCU - Universal Peripheral Compute Unit

Fusion PCU is a Rust framework for describing work once and executing it through capable processors, coprocessors, and other backends. Its intermediate representation, resource contracts, and runtime discovery let applications select where work runs while keeping execution requirements and failures explicit.

The project is experimental. ROCm is the current development and hardware-validation backend; additional backends will follow.
