# Native CUDA F32 SGD canonical benchmark

Actual `#[pcu]` source, a frozen explicit graph and a private native control use the same finite literal rate `(-0.25_f32)`. Both inputs change on every timed call. Separate Preserve and BackendOptimized cases cover 65 and 1,048,576 elements. Preserve executes `__fmul_rn(rate, gradient)` followed by `__fsub_rn(weights, product)`; optimized executes `__fmaf_rn(-rate, gradient, weights)`. The numerical contract explicitly grants Boundary, BackendDefined compound arithmetic and unspecified reproducibility. It grants neither checked training nor portable/native exceptional guarantees. No BLAS environment or emulation setting controls this private kernel.

Each warm full host call retains two input device allocations, performs two changing uploads, allocates one fresh full output, submits one kernel with its CUDA completion event, waits and checks API status, reads the entire output and releases it inside timing. There is no numerical fault status buffer or invented final-event shortcut. The source cache retains staging inputs; graph/native match that lifetime. Borrowed resident source fixtures separately verify original inputs stay readable and escaped outputs own their storage.

The independent full-output integer/dyadic oracle uses weights/gradient in eighth units. For the negative-quarter rate, each expected output is `(4*w_units+g_units)/32`, exact in both precision profiles. Every lane is checked outside each timed call. Untimed source/graph/native FMA witnesses independently require ratebits0x3f800001 and gradientbits0x3f7ffffe: Preserve returns +0, optimized returns +2^-46. Other preflights exercise default/strict/PortableV1/tight-underflow rejection, two distinct literal bodies/cache identity, nonfinite permission and finite retry, output shape and ownership after input/cache drop. This controlled domain does not prove all permitted native numerical behavior.
