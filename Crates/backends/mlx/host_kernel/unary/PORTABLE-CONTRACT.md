# Candidate PortableV1 exact floating unary implementation

This audit concerns checked Neg/ReLU on F16, BF16, F32, F64 and named OFP8 E4M3FN/E5M2. It does not describe integer-scalar unary arithmetic. Cold Portable unary opt-in is an active candidate; native requested-header qualification has not closed. This document is groundwork for its independent immutable proof. Existing normal/capacity certificates retain their original headers and limits.

The neutral `describe_portable_v1_unary_map` descriptor must succeed cold and its complete original requirements must survive preparation and offers. Reject/observable Clamp, all three underflow policies, actual input/output roles, direct/grid geometry and scalar reads remain explicit. An unused declaration is metadata, not another upload, owner affinity, or input allocation. New Portable offer identities must remain separate from the existing normal identities. Tensor graphs, composed maps, binary arithmetic, native MatMul and whole-model reproducibility are outside this candidate.

## Defined integer substrate

[Apple's Metal Shading Language specification](https://developer.apple.com/metal/Metal-Shading-Language-Specification.pdf), revision 2026-06-04, sections 2.1 and 3.1, defines the U8/U16/U32 carrier types, modular unsigned arithmetic, bitwise operations and zero-filling unsigned right shifts. Only unsigned magnitudes and bounded unsigned shifts are used. Narrow output values fit their declared carrier widths; F64 is two U32 limbs. No native floating arithmetic, comparison, conversion, rounding, contraction, signed overflow, division, arrival-order reduction or atomics determines the selected values.

`checked_unary.cpp::shader` emits bounded literals only. A finite Neg flips the format sign bit, including either signed zero. ReLU maps finite negative values and either zero sign to +0 and retains positive bits. Nonfinite input faults before selection. An exact selected subnormal cannot be tiny-and-inexact; IeeeAfterRounding and AllowGradualUnderflow therefore accept it. RejectSubnormalResult remains PCU's separate stricter result policy. Clamp retains the exact selected bits and returns a recovered notice; a nonfinite input remains fatal. BF16/OFP8 have their declared encodings and are not called IEEE basic formats.

Each logical lane writes a distinct payload location and one U32 status. F64 writes two distinct U32 locations. Native cold bounds require count and physical limb spans to fit signed 32-bit shape indices; consequently `2*i+1` is in range. A one-thread group divides the exact logical grid, so the implementation does not require nonuniform groups. Existing pinned MLX/runtime/device checks still apply. Defined integer operations explain numerical portability; actual M4 tests establish only the tested compiler/runtime deployment, not an invented M4-only admission gate.

## Physical and fault obligations

MLX owns the retained custom primitive, input/output arrays and actual stream. Exact native input shapes are primed cold, including full-capacity resident inputs; warm apply validates the frozen shapes and constructs no borrowed-input view. Host staging uses the separately retained logical minimum. Synthetic full-capacity priming incurs real cold uploads and temporary memory; no zero-cost or core-budget enforcement claim follows.

Every decoded nonzero status must pass the retained PcuCheckedScalarFaultLaw and actual logical extent before arbitration. The law validates legal classes/dispositions, not whether actual operands justify a reported record. Completion, private status readback and fallible cleanup precede publication. Fatal private work preserves preexisting immutable owners; unknown completion quarantines the actual session/pending work. Any fatal lane wins over all recovered lanes, then the lowest logical lane within that class wins. Host tails and resident prefix merges remain separately validated.

Before opt-in is recorded as conformance, requested-header source/prepared/native tests must independently cover all low-format encodings and F32/F64 signed-zero/nonfinite/subnormal/extreme/full-bit banks, complete tuples, geometry, unused/permuted bindings, host/resident/mixed routes, fatal/recovered publication, foreign sessions, retry and escaped owners. Genuine ordinary source is a fourth matched peer. Separate 64-changing-call caller/scorer/adapter census must distinguish Rust escaping ownership from SDK/native/device allocation and internal JIT, which remain unknown unless independently observed. Statistical timing requires an idle device and is not inferred from correctness/census.
