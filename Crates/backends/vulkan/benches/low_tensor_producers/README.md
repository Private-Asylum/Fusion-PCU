# Vulkan low-format immutable producer qualification

This correctness-only Criterion target compares actual `#[pcu]` inline-const Constant/UniformLike Add→Mul source, explicitly authored typed graph and independently handwritten packed GLSL. The genuine source and Rust midpoint oracle retain their ROCm fixture provenance; the GLSL imports no PCU arithmetic template, lowerer or emitter helper. Four low formats, N65/N4096, factor two/half, both requested function modes, both compound/precision permissions and three underflow policies give384 request cohorts and1,152 route keys. Scalar Add/Mul mode intentionally normalizes to None, so requested Boundary/Strict do not establish distinct scalar arithmetic laws. Unspecified reproducibility, Reject range; no Portable/Clamp/compact/F128/F256/division widening.

Each shader invocation owns a complete packed32-bit output word, avoiding byte-store races. Independently decoded binary64 dyadics and neighboring finite encoding midpoint search implement ties-even, overflow and tininess. Only the native reference requires shaderFloat64; this is not a production low-format capability requirement. Separate per-lane Add/Mul codes are scanned by phase then invocation, preserving graph fault order. The fused shader may privately compute Mul in healthy lanes even when another lane has an Add fault; no private output publishes after any fault. This differs physically from two PCU graph kernels and is not a same-work performance comparison.

The native owner uses a separately selected matching physical UUID, five disjoint HOST_VISIBLE|HOST_COHERENT buffers, padded and initialized complete words, coherent persistent mappings, host→compute and compute→host dependencies, a retained command and one terminal fence. It retains all native ownership through submission; unknown completion attempts idle proof and abandons unsafe-to-free resources. File/compiler input is cold only; no compiler or I/O runs warm.

Healthy changing inputs, exact bit results, invalid/overflow/underflow, mixed fault-stage order, rollback, retry, short spans and tails are compared. Selected source literal mutation/consumption/replay/cache-clear and detached explicit graph literal lifetime are separate witnesses. Shape/policy refusal is also exercised by the existing cold reciprocal test. No CPU fallback is used. Companion native owner stores fixed dense input/constant/splat banks; graph/source produce fresh terminal output owners, so allocations and command vectors are disclosed separately.

Run `cargo bench -p fusion-pcu-vulkan --features tensor --bench low_tensor_producers -- --test` for native correctness. Compile a separate `--all-features` target for explicit CountOnly insights and64-changing-call Rust/API census. Disabled insights remove ledger fields/call sites; the benchmark-only allocator still forwards allocations normally. This target refuses statistical timing without `--test`; no latency claim is produced here. A future same-work native decomposition is a separate performance gate.
