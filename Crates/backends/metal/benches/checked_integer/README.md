# Checked fourteen-width integer peers

Each workload contains genuine generic `#[pcu]` source prepared before calls, ordinary global source, independently built typed IR with nonordinal bindings, and a direct native UInt32-limb checker. Add/Sub/Mul, Reject/Clamp, fourteen signed/unsigned widths from 8 to 512 bits and extents65/4096 give672 peers. Every call stages two fresh initialized inputs, allocates private output/status, waits for terminal completion and scans all diagnostics, then transactionally publishes a host prefix and drops temporary owners. Three changed input banks and untouched output tails are verified before and after each independently filterable registration.

`--test` is semantic smoke, not a statistical timing claim. Allocation-census is a separate build and reports actual caller Rust allocation/reallocation/free counts. Objective-C/native/device allocations and descriptor creation are not counted by that allocator. No zero-allocation, resident in-place, Portable or operation-cost claim is inferred. Source-prepared specialization, neutral lowering and native compilation happen before the repeated calls.
