# Low-format immutable producers, paired arithmetic and census

`low_tensor_producers` compares genuine `#[pcu]` inline-const Constant/UniformLike source, independently authored typed graph, and handwritten CUDA arithmetic for F16/BF16/F8E4M3FN/F8E5M2. It computes Add then Mul: the constant repeats one/minimum-subnormal/negative-zero; the splat is two or half. N65 and N4096, both requested function modes, both compound/precision permissions and all three underflow policies give 384 request cohorts and 1,152 route keys. Scalar Add/Mul intentionally normalize numerical mode to None: the requested modes do not constitute distinct scalar arithmetic laws. Reproducibility is Unspecified and range is Reject; Portable/Clamp/compact and wider floats are excluded.

The handwritten asset imports no PCU emitter or arithmetic helpers. It constructs IEEE binary64 powers/sign/absolute values directly with bit casts, requiring no host math headers, and decodes raw dyadics to binary64, searches neighboring finite encodings and applies ties-even, overflow midpoint and unbounded-exponent tininess classification. Low significand precision is at most11 bits; products fit22 bits and remain normal in binary64. Add pairs near low-format rounding or cancellation boundaries fit binary64 exactly; widely separated addends cannot move the low-format rounded result or tiny boundary. This is bounded low-format arithmetic, not a general exact-real binary64 claim. Its mechanically host-adapted 7,776 boundary rows are frozen in oracle/vectors.txt and compared with neutral primitive laws by the focused producer_control test. The separate Rust midpoint oracle also checks each stage against primitive laws. The immutable reciprocal7,776-row table SHA110a5fc6628d00f7afa18cd70f9d659e7459a6102f6e8b7174a033327ff42e11 is unchanged. CUDA replaces HIP bit casts with documented header-free [CUDA type-casting intrinsics](https://docs.nvidia.com/cuda/cuda-math-api/cuda_math_api/group__CUDA__MATH__INTRINSIC__CAST.html); the fixed-expression control imports no PCU math. No Python dependency is introduced.

Two same-stream kernels preserve operation order. Add's status is immutable during Mul; separate status words permit earliest invocation within each phase. Host publication occurs only after terminal completion and a healthy disposition. Invalid operands, competing faults across phases, exact/tiny-inexact underflow, retry, short spans, unchanged publication and tails are checked. Genuine zero-argument vector Constant/Uniform companions and typed selected literal outputs have separate mutation/consumption/replay/cache-clear lifetime checks; source unused CPU owners remain legal under explicit GPU routing, while used foreign owners refuse affinity.

The physical endpoints differ deliberately and are disclosed: PCU routes return a fresh resident owner; explicit graph uploads a fresh input owner; handwritten SDK retains pinned endpoints and private output/status buffers, uploads three dense banks, and waits one final event after two kernels. Census reports these boundaries rather than treating allocation differences as arithmetic changes. It measures 64 alternating healthy payload calls in a separately compiled allocation-census executable, with exact provider-visible CUDA and handwritten SDK count vectors. It does not count driver-internal heap activity.
