# Composed integer controls

This Criterion target compares genuine `#[pcu]` source (ordinary and explicitly prepared), independently authored typed IR, and a handwritten Vulkan SDK owner. Integer `native/arithmetic.comp` uses its own unsigned 32-bit limb Add/Sub/full product and signed limits; it imports no PCU arithmetic shader, emitter, or lowering helper. The SDK owner shares host fault-law metadata to translate native status, while arithmetic and submission remain independently authored.

The registered native expression is `(input + input) * input` or discarded checked Add followed by input reload, N65, all fourteen integer carriers. Packed U8/U16 invocations own complete output words. Source/IR/compiler refusal and separate staged/scalar-seed/Sub/N4096 proofs must not be inferred from this fixed native expression. Ordinary source permission/header checks, changing inputs, untouched tails, overflow/underflow, Reject rollback, Clamp notice and healthy retry are asserted before any timing.

Run the release target with `--test` for correctness only. `PCU_COMPOSED_CENSUS=1` requests a separate 64-changing-call Rust allocation/free and cold-selection census. Statistical timing requires an independently checked idle device and controlled ownership; successful correctness logs are not latency measurements.

The existing `insights` feature enables an explicit additional diagnostic: `PCU_COMPOSED_API_CENSUS=1`. It attaches separate caller-owned fixed CountOnlyClock ledgers to PCU owners and the handwritten SDK owner before construction. Each warm route snapshots both ledgers, checks exactly 64 fence resets/submissions/waits on its owner, and refuses all other warm SDK operations. Warm probes borrow retained ledgers, without Rc clones, clock samples or discovery. Disabled compilation removes the diagnostic module, fields, TLS attachment and call-site probes. SDK counts are attempted provider-visible ash calls; they do not report driver-internal allocations. Cold total vectors include discovery performed inside attachment. Provider thread-cache owners may survive the benchmark's local scope; total vectors are not a complete provider destruction certificate. Handwritten owners retain their construction ledger through terminal Drop even if the current attachment changes.

The integer arithmetic certificate and enabled SDK accounting certificate use separate frozen source cuts. Older helper-sharing native controls remain historical evidence with their original limitation.
