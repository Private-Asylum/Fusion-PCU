Logical element type/count remain distinct from verified physical UInt8/UInt16/UInt32 carriers;32–512-bit encodings use limbs. Every byte extent, dense stride, pointer access and shape/session check must use the appropriate representation. Official F32 bit views retain the same authentic session and immutable owner, while their cached descriptors and any source-conditioned physical copy are accounted separately. No unrelated provider import or physical-GPU identity bypass exists.

Joint division preflights both destinations, completes both private results and status, performs both required private reads and checked temporary cleanup, then publishes both. Fatal work preserves previous immutable owners; unknown completion retains pending actual native resources and quarantines the actual session. Longer resident READ inputs are not implicitly trimmed. Unused declarations are not permission to ignore explicit loads.

Operation costs remain unknown unless an exact matching boundary is measured. Caller Rust allocation census excludes native/device heap. Escaping-owner allocation/refcount and terminal read/drop are real ownership costs. Native allocator/reserve limits do not yet enforce core memory-headroom policies. Three external-image injection fixtures remain unqualified. No full-provider or whole-model portability claim follows from these bounded certificates.
